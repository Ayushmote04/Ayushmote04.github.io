# Ayush Mote — Portfolio

A responsive personal portfolio built with HTML, CSS and JavaScript.

## Run locally
Open `index.html` in your browser.

## Publish with GitHub Pages
1. Create a repository named `Ayushmote04.github.io`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. After GitHub Pages finishes publishing, visit `https://ayushmote04.github.io/`.

Update the project details and contact links before sharing the portfolio with recruiters.
